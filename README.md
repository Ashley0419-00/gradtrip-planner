# 同路 GradTrip — 毕业旅行拼团规划

在线演示：https://gradtrip-ashley.aaashiii0419.chatgpt.site

为毕业旅行提供从成员偏好到行程与结算的完整轻量交互。纯 HTML/CSS/JavaScript，无构建依赖。

## 功能
- 成员预算、目的地、日期、旅行节奏录入与编辑
- 日期交集与预算冲突提示；透明的目的地共识评分
- 规则模板生成行程；编辑/添加/删除每日安排
- 按实际参与人均摊，人民币分整数计算，净余额结算建议
- localStorage本机保存，URL快照分享，TXT导出
- 移动端响应式布局，原型边界说明与重置演示数据

## 运行与部署
静态服务器根目录指向 `dist`，如 `npx serve dist`。可使用 GitHub Pages（发布dist目录需配置工作流）、Vercel或任意静态托管。

## 原型边界
所有初始成员、账单是样例；目的地费用和景点是离线参考，不保证实时准确。无实时大模型、账户、云数据库、多人实时协作、票务预订、在线支付。共享链接包含计划快照，修改后需重新分享。正式评审链接应使用上方固定首页域名。

## 产品设计取舍
优先帮助组织者显式发现时间和预算冲突，而不是假装一键解决所有人偏好。透明规则避免黑盒推荐。分账仅向实际参与者收取，并可追溯垫付人与参与人。后续可扩展服务端协作与带权限的邀请、真实LLM结构化规划、地图交通、实时价格和变更通知。
